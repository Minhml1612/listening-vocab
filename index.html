Kết nối Google Docs tự động

Để web tự động lấy từ vựng ngay khi bạn ghi thêm vào Google Docs mà không lo lỗi phân quyền, bạn chỉ cần tạo 1 Web App nhỏ hoàn toàn miễn phí trên chính Google Docs của mình:

  1. Mở file Google Docs của bạn (Mở tại đây).
  2. Chọn menu Tiện ích mở rộng (Extensions) > Apps Script.
  3. Dán mã từ file google-apps-script/Code.gs vào.
  4. Nhấn Triển khai (Deploy) > Tùy chọn triển khai mới (New deployment) > Chọn Ứng dụng web (Web app).
  5. Mục Người có quyền truy cập (Who has access): chọn Bất kỳ ai (Anyone) > Nhấn Triển khai.
  6. Sao chép đường dẫn (URL) dạng https://script.google.com/macros/s/.../exec và dán vào ô bên dưới!

Dán URL Web App triển khai từ Google Docs của bạn.

Không bắt buộc. Nếu để trống, web vẫn tự động có phát âm chuẩn, nghĩa và ví dụ Oxford.
